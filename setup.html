📚 BB Deadline Notifier · 一键部署

为南方科技大学 Blackboard 作业截止日期建立邮件提醒。本页面是纯静态页： 你填入的信息只从你的浏览器直接发往 GitHub 官方 API，没有也不经过任何中间服务器，页面不保存任何内容。

它将为你做什么：在你的 GitHub 账号下创建一个私有仓库（由公开模板生成），写入提醒所需的 Secrets，并触发首次运行。此后每天 08:00 一封未提交作业日报、08:10 / 14:00 / 20:00 三次 48/24/12 小时分档提醒（已提交的也会提醒并标注「已提交·请复核」）。

第一步：准备材料（5 分钟）

  1. GitHub 账号（没有就注册一个，免费）。
  2. 一个个人 QQ 邮箱 + SMTP 授权码：邮箱网页版 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码（16 位字母，不是邮箱密码）。
  3. 你的 Blackboard 日历链接（ICS_URL）：登录 bb.sustech.edu.cn → 左侧「日历」→ 页面底部 Get External Calendar Link → 复制；若以 webcal:// 开头，改成 https://。
  4. 一个 GitHub 访问令牌（PAT）： 创建细粒度令牌 → 有效期选 7 天 → Repository access 选 All repositories → 权限勾选： Administration: Read and write（建仓库）、Secrets: Read and write、Actions: Read and write，其余默认。 部署完成后即可撤销该令牌——所有配置已写入你自己的仓库，与令牌无关。

第二步：填写信息

▶ 全保真模式（选填）——填了才有课程名和「已提交」过滤；留空则为纯 ICS 模式
部署完成！ 首次运行已在后台触发，几分钟内你的收件邮箱会收到第一封测试邮件。

打开你的仓库 · 查看运行状态

现在请去撤销 PAT： 令牌管理页 → Delete。 之后想改配置，直接在仓库 Settings → Secrets and variables 里编辑即可。

不想用 GitHub 的同学（零安装方案）

我只要手机上能收到提醒，不想建仓库

把上面第 3 项获取的 ICS 链接订阅进手机日历即可：iPhone「设置 → 日历 → 日历账户 → 添加账户 → 其他 → 添加订阅日历」，粘贴链接；再在 设置 → 日历 → 默认提醒 里设提前量。 一次配置、自动同步、零维护——代价是没有邮件汇总和提交过滤，刷新也略有延迟。
