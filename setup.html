作业截止日期提醒。

为南方科技大学的 Blackboard 建立邮件提醒：每天一封未交作业日报，加上 48 / 24 / 12 小时分档催交。 全部运行在你自己的 GitHub 账号里，你的电脑无需安装任何东西。

两种模式

默认基础模式；在下方开启登录模式并填写学校凭据即可升级。

基础模式（无需登录）登录模式
工作原理 直接订阅 Blackboard 的公开日历链接（ICS）——和你把日历订阅进手机是一回事，全程不接触学校账号。 GitHub 云端服务器用你的学号 + 密码登录学校系统，读取成绩册里每项作业的截止时间与提交状态。凭据只存放在你仓库的加密 Secrets 中，任何网页（包括本页）都接触不到它。
课程名 不显示 显示（如「SME105 电路分析基础」）
已提交的作业 无法识别，临近时一律提醒 日报自动隐藏；分档提醒标注「已提交·请复核」作为保险
出分提醒 不支持 可选开启
邮件标识 标题带 [降级] 前缀 无前缀
凭据暴露面 零学校凭据（最小风险） 学校密码存在于你自己的私有仓库 Secrets

准备材料

  1. GitHub 账号（免费注册，一分钟）。
  2. QQ 邮箱 + SMTP 授权码：邮箱网页版 → 设置 → 账户 → 开启 SMTP 服务 → 生成授权码（16 位字母，不是邮箱密码）。
    查看官方指引截图

    截图来自 QQ 邮箱官方帮助 · 授权码说明； 开启服务需要手机短信或微信扫码验证，授权码只显示一次，记得保存。

  3. BB 日历链接：登录 bb.sustech.edu.cn → 左侧「日历」→ 日历页面左下角 「获取外部日程表链接」 → 复制弹窗中的 URL； webcal:// 开头请改为 https://。
    查看操作截图（隐私内容已打码）

    上图：日历页面，入口按钮在左下角（示例图的课程列表已打码）。 下图：点击按钮后的弹窗——里面的 iCal URL 就是你要复制的 ICS 链接（示例图中已打码，因为它等同于你的私人令牌，不要发给任何人）。

  4. GitHub 访问令牌（PAT）：创建细粒度令牌 → 有效期建议选 永久（No expiration）——以后回来改提醒时间、换邮箱都不用重建令牌，不再需要时随时可撤销。 → Repository access 选 All repositories → 权限勾选： Administration · Read and write（建仓库）、Secrets · Read and write、 Actions · Read and write、Contents · Read and write 与 Workflows · Read and write（后两项用于写入你自定义的提醒时间）。
    查看完整创建路径与步骤截图（个人内容已打码）

    路径：右上角头像 → Settings → 侧栏最底部 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。

    截图取自真实创建流程；用户名、头像、已有令牌列表与仓库信息均已打码。 权限项在 Repository permissions 的下拉列表里逐个搜索添加，访问级别选 Read and write。

不想用 GitHub？

我只要手机上有提醒，不想建仓库

把上面第 3 项的 ICS 链接订阅进手机日历即可：iPhone「设置 → 日历 → 日历账户 → 添加账户 → 其他 → 添加订阅日历」，粘贴链接；再在 设置 → 日历 → 默认提醒 里设提前量。 一次配置、自动同步、零维护——代价是没有邮件汇总和提交分流，同步也略有延迟。
